# 选屏与黑屏手势亮屏

2026-11-04，v0.4.0。发布 SHA-256：`08485c627b1b00a888d94ed95ec50119457731785821dd36d1c2238cdbd3ae17`；当前发行验证见[VALIDATION](VALIDATION.md)。

## 使用

1. 设置 → 屏幕 → 切换屏幕，取消“全部屏幕”后勾选所需屏幕，点击保存。
2. 全局热键、桌面热键、按钮和定时使用同一份已保存范围。黑窗、背光和 HDR 都只作用于所选屏幕；内外屏背光开关分别决定是否调节该类型的背光。
3. 亮屏时恢复本轮保存的原亮度与 HDR。改选屏幕不会丢弃上轮待恢复的设备。

旧配置和“全部屏幕”包含所有当前及以后连接的屏幕。逐屏选择按设备身份保存，显示编号改变不自动换目标；未连接的已选屏保留，全部目标离线时拒绝熄屏，不改动其它屏幕。镜像屏共用一个桌面，需一起选择或先改为扩展显示。多屏列表分页显示，不因离开当前页而丢弃其它页的选择；取消和 Esc 不保存。

“压暗外接屏”“压暗内置屏”位于同一行的左右两半，两个开关仍独立保存。只熄灭部分屏幕时保留全局光标，方便使用其它屏幕；全部屏幕被覆盖时继续采用原有光标策略。熄屏期间接入未选屏时，也会恢复全局指针。

## 同一桌面热键亮屏

亮屏状态仍要求真正的 Explorer 桌面空白，排除图标、窗口和酷呆的未知自绘桌面。黑屏状态改为确认点击落在本进程可见黑窗的实际区域内，允许从盖在应用窗口上的黑窗唤醒，不再要求看不见的底层必须是桌面。

单双击继续使用各自的设置；黑窗之外、未选屏和区域空隙不触发桌面亮屏。全局热键仍按全局范围生效。跨明暗状态的第一次点击、按住事件和排队旧输入不能拼成新双击；钩子不执行调光或无障碍 RPC，不吞输入。

## 实现边界

- `config.rs` 保存 `selected_displays`：`None` 为全部，显式列表为固定设备身份，空列表不会回退到全部。DDC/HDR 按完整 monitorDevicePath 匹配，WMI 按严格 PnP 身份与已支持的实例后缀匹配，未知映射拒绝。
- `native.rs` 的选屏过滤与测试白名单交叉，在物理屏枚举、亮度读取和写入之前生效；WMI 查询按完整实例限定。`Presented` 直接转发 `scan_selected`，避免包装层退化成扫描后的过滤。恢复不受新选择限制，仍按 journal 重新绑定和精确回读。
- `native::displays()` 仅查询逻辑拓扑与矩形，不读取亮度。App 启动缓存、打开选屏窗口或收到显示拓扑变化时刷新；正常切换没有新增亮度采样、轮询等待或固定延迟。
- 一个黑窗使用所选矩形的并集区域，保持现有显示／光标同一 UI 分派、淡入和捕获排除。按[微软 SetWindowRgn 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)移交区域所有权；并集采用[CombineRgn](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-combinergn)。

## 验证

v0.4.0 通过 fmt、全目标全 feature Clippy、release 构建及 67 项常规测试（45 lib、13 binary、5 选屏集成、4 恢复集成）。新增反例覆盖配置兼容、空选择／断连不回退、改选先恢复旧基线、严格身份匹配、Native 白名单交叉、包装层前置转发、黑窗区域及跨明暗输入。

最终 EXE 的隔离窗口消息回归共 8 组：选屏保存／取消／重启、零选择禁保存、断连身份保留、11 条屏幕记录的分页、同行独立开关、两套热键录入，以及既有启动／滚动／主题／关于。浅深截图已目视检查，测试窗口创建前限定 Type-C。

原生黑窗区域探针在 Type-C 显示两个小区域：两个区域接受，区域空隙、窗外及隐藏后的窗口拒绝。没有注入鼠标输入或操作亮度。这证明区域门禁，不冒充用户人工双击亮屏验收。

最终 EXE 仅在 Type-C 白名单执行两轮普通 Dark/Light，配置同时只选择 Type-C：每阶段只有一条 DDC 请求，黑窗矩形精确等于该屏，原亮度逐轮恢复，光标位图不变、无残留恢复记录，正常退出 0。

| 两轮结果 | 第 1 轮 | 第 2 轮 |
| --- | ---: | ---: |
| 熄屏完整请求 | 190.6 ms | 184.8 ms |
| 亮屏引擎到 UI 恢复确认 | 60.5 ms | 73.3 ms |
| 亮屏完整请求 | 106.3 ms | 118.9 ms |
| 亮屏硬件批次（含精确回读） | 104 ms | 117 ms |

这里的 UI 确认不是面板物理响应，也不是三屏测量。没有做新的人工双击到实际亮屏、HDR 故障、热插拔或远控输入验收；HDMI 工作屏没有参与硬件测试。
