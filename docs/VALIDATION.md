
## 构建检查

发布构建通过 `cargo fmt --check`、全目标全 feature Clippy、37 项 lib 测试、1 项 binary 测试和 release 编译。

在仓库根目录运行 `build.bat` 可重新执行这些检查。领域测试涵盖配置、原子存储、定时、设备恢复、取消和写入确认；真实驱动、窗口和显示器仍需对应实机验证。

## 资源占用

使用真实 Native 后端、单个独立进程采样，没有硬件调光，也没有调用工作集裁剪。

| 状态 | Private Commit | Working Set | GDI | USER | 句柄 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 仅托盘冷启动 | 2.38 MiB | 13.26 MiB | 10 | 7 | 179 |
| 设置页显示 | 3.11 MiB | 17.28 MiB | 45 | 59 | 202 |
| 设置页隐藏/显示 50 次后 | 3.21 MiB | 17.53 MiB | 45 | 59 | 202 |

Private Commit 描述私有提交内存，Working Set 描述当前驻留内存，二者不能混为同一个“占用”。隐藏面板后 Windows 和程序仍可能保留已分配资源；该结果不构成长时间泄漏测试。

[原始资源结果](../checks/evidence/resources-v0.3-final/results.json) · 开发脚本：`checks/measure_resources.py`。

## 切换延迟

当前 EXE 在一台 Type-C 外接显示器、设备白名单、Ready 模式、`delay_ms=0`、未改变 HDR 的条件下，完成一轮真实普通熄屏/亮屏。通过隔离配置和有界窗口消息发起，未注入鼠标键盘输入。

| 指标 | 熄屏 | 亮屏 |
| --- | ---: | ---: |
| 请求后首次观察到黑窗 / 桌面恢复 | 16.9 ms | 156.0 ms |
| 引擎开始到 UI 确认 | 20.3 ms | 160.4 ms |
| 应用请求到完整处理结束 | 212.2 ms | 191.6 ms |
| 硬件批次，含精确回读 | 118 ms | 122 ms |
| 批次内最慢写入返回 | 56 ms | 61 ms |

这是单轮样本，不是多轮统计。首次可见变化受观察采样影响，不能等同于面板物理响应；硬件批次不包含设备发现和 journal 准备，也不能当成完整应用链路。

操作后按设备身份验证原亮度精确恢复，光标恢复一致，无待恢复记录，进程退出码为 0。

[当前链路结果](../checks/evidence/normal-path-typec-v0.3-final/results.json) · 开发脚本：`checks/test_normal_path_latency.py`。

## 设置与启动

当前 EXE 的定向验证通过三组：

- 合并后的开机静默启动、实际启动命令、重复静默启动、手动启动重新显示面板。
- 隐藏滚动条后的滚轮、键盘滚动和主题切换。
- 关于窗口文案、确定、`Esc`、关闭和资源释放；无提示音的依据是自定义窗口不调用 `MessageBox` / `MessageBeep`，没有录制音频回环。

此验证使用隔离数据目录、测试注册表分支和有界 Windows 消息，不等同于真实鼠标拖动或全部输入法交互测试。

[启动与面板结果](../checks/evidence/startup-v0.3-final/results.json) · 开发脚本：`checks/test_startup_panel_polish.py`。

## 已知边界

- 上述当前哈希的正常切换样本仅包含一台 Type-C 显示器，不能外推所有多屏组合。
- 真实 HDR 切换、设备热拔插、WMI 故障重连和注销登录恢复需要进一步实机验证。
- 第三方远控连接自动识别尚未完整闭环；UU 私有 IPC 保持禁用。需要可靠保留光标时，可使用显式“始终保留”。
- README 截图展示实际界面状态，不单独证明连续拖动、硬件恢复或远控兼容性。
- 黑窗捕获排除取决于 Windows 与捕获软件路径，背光最低亮度取决于显示器硬件。

## 运行开发验证

`checks/` 下的 Python 工具用于 Windows 开发环境，部分截图脚本需要 Pillow。运行前先阅读脚本参数和设备筛选条件。

```powershell
python -m pip install -r .\checks\requirements.txt
```

UI 验证采用 `--ui-test --data-dir <绝对路径>` 使用模拟调光和独立配置；真实硬件链路使用 Native 后端及 `--restrict-id <完整设备身份>` 将范围限定到目标设备。带硬件操作的测试和 Rust examples 会实际改变显示器状态，不能作为无副作用的普通烟雾检查运行。

测量时保留恢复记录和精确回读，分别报告准备、写入、回读、可见恢复和完整请求时间。失败时保存现场，正常恢复并等待线程结束后再退出。
